## 👨‍💻 About Me

I trained as an **Electrical Engineer** and still think like one — figure out the
constraints, cut the scope to what actually matters, then build the smallest
thing that works.

These days most of that energy goes into shipping software end to end: iOS apps
in **Swift/SwiftUI**, cross-platform apps in **React Native (Expo)**, web
products in **Next.js**, and Python tooling for the odd jobs in between. I do
the whole loop myself — data model, security rules, UI, payments, CI, store
submission, and the README that explains it.

A few things I care about:

- **Small and cheap to run.** Most of what I build is designed to cost close to
  nothing until it has real users.
- **Security is not a phase.** Firestore rules get their own test suite; secrets
  stay server-side; access is gated by default.
- **Docs are part of the product.** If a project can't be picked up cold from its
  README, it isn't finished.
